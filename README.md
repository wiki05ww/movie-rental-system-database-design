# Movie Rental System (VOD) – Database Design Project

## Opis projektu
Projekt przedstawia koncepcję systemu wypożyczalni filmów online (VOD), skupiając się na modelowaniu danych oraz projektowaniu struktury systemu.

System umożliwia przeglądanie katalogu filmów, wypożyczanie ich oraz zarządzanie kontem użytkownika.

## Zakres projektu
- model relacyjnej bazy danych
- projekt encji i relacji (ERD)
- diagramy UML (use case, DFD, sekwencji)
- analiza przepływu danych
- prototyp interfejsu (Figma)

## Baza danych
Projekt obejmuje strukturę bazy danych zawierającą:
- użytkowników
- filmy
- wypożyczenia
- kategorie

## Funkcjonalności

### Użytkownik:
- rejestracja i logowanie
- przeglądanie filmów
- wypożyczanie filmów
- historia wypożyczeń

### Administrator:
- zarządzanie filmami
- zarządzanie użytkownikami
- podgląd wypożyczeń

## Diagramy
Projekt zawiera:
- ERD (diagram encji)
- diagram przypadków użycia
- diagram przepływu danych (DFD)
- diagram sekwencji
